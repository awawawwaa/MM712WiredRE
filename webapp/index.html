No Debounce Time/Button Response Time control here on purpose: setting it in Cooler Master's own software doesn't survive a power cycle — it's back to the 6 ms default every time, on every value tried. It does nothing, so there's nothing for this webapp to set either. See the README for the capture that showed this.

Write all settings sends every stage's DPI/enabled state, the active stage, and the polling rate — use this after editing any DPI value, enabling/disabling a stage, or changing polling/LOD.
Switch active stage only sends one packet that just changes which stage is active. It does not write DPI edits or the polling rate — the mouse keeps whatever those were set to on its last full write.

RGB

Static has no speed control — Cooler Master's own software only exposes color and brightness for it, matching what's offered here. Off has no adjustable parameters at all. Color Cycle, Electric Slide, Trigger/Click and Custom were explored during reverse-engineering (see the README) but misbehaved when driven live from this webapp, so they were removed rather than shipped half-working.
